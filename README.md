# 內湖漫遊

一款沒有終點的散步遊戲。在台北市內湖區自由走動，走訪 17 個真實地景、收集 30 件在地圖鑑。

**直接玩 → https://HankGit2023.github.io/neihu-stroll/**

## 玩法

| 操作 | 說明 |
|---|---|
| `W A S D` / 方向鍵 | 走動 |
| 按住螢幕左半邊拖曳 | 觸控搖桿，推多遠就走多快 |
| 維持滿推半秒 | 加速衝刺 |
| `E` | 查看地點、撿東西、跟人說話 |
| `1` `2` `3` | 切換右側分頁 |

時間會自己走，約十六分鐘一個日夜。天黑後路燈會亮，山上和園區才有東西可以撿。

## 內容

- **17 個地標**：大湖公園的錦帶橋、碧湖公園、白石湖吊橋、碧山巖、金面山剪刀石、文湖線三站（港墘 BR17 / 文德 BR18 / 大湖公園 BR20）、內科園區、737 巷、基隆河左岸、麥帥二橋、舊宗路賣場、五分埤、內湖花市、運動中心
- **30 件圖鑑**：白鷺鷥的羽毛、碧湖的煤矸石、吊橋的龍骨螺栓、福州胡椒餅、排隊號碼牌……其中 4 件只在天黑後出現
- **同事**：羅素、Kevin、Hank、Vivian。問他們「要一起抽煙嗎？」就會跟著你走，停下來不動他們會自己點菸
- **馬哥**：穿水藍色風衣在地圖上隨機遊蕩，可以揍，隊友會一起上

## 技術

單一 HTML 檔，Canvas 2D 全程式繪製，沒有建置步驟、沒有函式庫、沒有後端。進度存在瀏覽器的 localStorage。

地圖取材自內湖區的真實地景，位置與比例為遊戲所需重新編排，不是地圖。
